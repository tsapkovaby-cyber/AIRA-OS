# AIRA OS

AIRA OS is a controlled digital-identity operating system. Sprint 012 adds its
registry-driven framework for specialized agent workers; agents never become or
redefine AIRA Core.

## Agent framework

The implementation is in [`backend/agents`](backend/agents), its security and
architecture documentation is in [`docs/agents`](docs/agents), and the completed
sprint report is in
[`docs/16_Codex/reports/Sprint_012_Report.md`](docs/16_Codex/reports/Sprint_012_Report.md).

Run the test suite with:

```bash
python -m pytest
```
