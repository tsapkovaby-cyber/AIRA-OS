# AIRA OS

This repository contains the Sprint 024 Live Language Classroom MVP. It provides a
transport-independent Python classroom controller, Telegram voice transport,
adaptive conversation and correction policies, canonical AIRA speech integration,
student-isolated learning memory, and RU → EN / EN → RU end-to-end tests.

See the [Sprint 024 report](docs/16_Codex/reports/Sprint_024_Report.md) and the
[classroom documentation](docs/education/Live_Classroom.md).
