# AIRA-OS

AIRA-OS is the architecture workspace for AIRA operating system components.

## Sprint 006: Decision Engine

The Decision Engine determines how AIRA acts by converting evaluated evidence into explainable, reproducible, and auditable decisions. The Sprint 006 implementation is architecture-only: it defines models, policy classifiers, approval workflow, storage boundaries, API methods, documentation, and tests without LLM inference, autonomous execution, external integrations, or business workflows.
