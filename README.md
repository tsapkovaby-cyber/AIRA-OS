# AIRA OS

AIRA OS is a founder-controlled operating layer for supervised AI work. Sprint 013 adds the authenticated Founder Dashboard and Control Center.

## Dashboard

```bash
npm install
npm run dev
```

Open `http://localhost:3000/login`. The local demonstration account is `founder@aira.local` / `founder-demo`; production deployments must replace the demo authentication adapter.

See [`docs/dashboard/README.md`](docs/dashboard/README.md) for architecture, security, and operating guidance.
