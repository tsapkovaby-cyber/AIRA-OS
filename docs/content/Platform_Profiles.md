# Platform Profiles

Platform adapters transform structure, never factual conclusions.

- **Telegram:** depth, useful detail, links, and discussion.
- **Instagram:** visual hierarchy, accurate opening, compact/saveable value; carousel, reel, story, caption.
- **TikTok:** rapid context, problem, demonstration, concise conclusion; no deceptive hooks.
- **YouTube Shorts:** hook, problem, demonstration, result, limitation, conclusion.
- **YouTube long form:** introduction, problem, context, method, demonstration, results, comparison, limitations, verdict, sources, disclaimer.

Hooks may create curiosity but cannot overstate evidence. CTAs must be contextual rather than manipulative.
