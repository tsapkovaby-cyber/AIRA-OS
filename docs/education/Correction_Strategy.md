# Correction Strategy

Errors enter a bounded correction buffer after a confident transcript. Selection order is meaning-breaking, repeated, lesson target, high-frequency, pronunciation, then style. Meaning-breaking issues can be immediate; normal issues wait for a natural checkpoint (every three student turns by default), and only one is released. Recasts may preserve flow.

ASR confidence below 0.70 creates no correction. AIRA confirms the transcript or asks for repetition. Feedback names the original and improved form and gives a brief reason; it does not correct every error or turn conversation into a lecture.
