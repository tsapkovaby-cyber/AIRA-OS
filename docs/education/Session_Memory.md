# Session Memory

At completion, `LearningMemory` stores a student-scoped summary: practiced goal, important confident errors, activated vocabulary, speaking measures, recommended review, and next lesson. Retrieval requires the same student ID, preventing cross-student access. Future sessions can inject weak items and avoid repetitive topics.

The memory boundary intentionally accepts summaries rather than audio. Personal interests are used only when approved and are not promoted automatically to durable memory.
