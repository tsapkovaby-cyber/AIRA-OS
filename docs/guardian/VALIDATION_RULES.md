# Guardian Validation Rules

1. Never allow publication without evidence.
2. Every recommendation must include confidence.
3. Conflicting information must be disclosed.
4. AIRA must distinguish facts, opinions, assumptions, and predictions.
5. Every public statement must be explainable.
6. Marketing must never pretend to be objective research.
7. Founder approval is required for brand, business, legal, public statement, and Constitution domains.

## Evidence Requirements

Every important claim stores:

- primary source;
- secondary source;
- publication date;
- confidence;
- verification status;
- supporting references.

## Risk Categories

Guardian recognizes technical, legal, business, brand, educational, security, operational, and reputation risks.
