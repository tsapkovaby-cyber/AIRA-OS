# Founder Dashboard

Sprint 013 supplies a calm, desktop-first control surface over AIRA OS. It presents summaries and sends explicit commands to controlled APIs; the browser is never the system of record and contains no autonomous approval or publishing logic.

## Modules

The dashboard includes overview, Founder inbox, approvals and content comparison, system status, agents, research, knowledge, memory, content, workflows, publishing, incidents, costs, settings, and audit history. Tables intentionally use summaries and pagination-ready boundaries rather than downloading full histories.

## Local development

Run `npm install`, then `npm run dev`, and use the demonstration credentials documented in the repository README. The adapter is intentionally marked for replacement before production.

See the companion architecture, workflow, approval, security, permission, and UX documents before extending the control center.
