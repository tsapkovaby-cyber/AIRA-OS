# Metrics and Rubrics

Metrics carry unit, method, direction, weight, raw and normalized values, confidence,
and evaluator. Min-max normalization is deterministic and reverses lower-is-better
metrics. Rubrics add a versioned scale and explicit criteria. Human ratings remain in
their own result field and accept only values from 0 through 10.

Generic candidates include quality, accuracy, consistency, reliability, latency,
cost, ease of use, repeatability, and business value. Metric-specific winners are
reported, but the comparison API deliberately refuses to manufacture an overall
winner.
