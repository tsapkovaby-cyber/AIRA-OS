1. О сервисе

AIRA — виртуальный AI-ассистент. Telegram-бот: @AIRA_influenser_bot. Общаясь с AIRA, пользователь взаимодействует с системой искусственного интеллекта.

2. Какие данные могут обрабатываться

В зависимости от используемых функций AIRA может обрабатывать:

  • числовой идентификатор пользователя Telegram;
  • имя пользователя Telegram и отображаемое имя;
  • сообщения, отправленные AIRA, и контекст разговора;
  • голосовые сообщения, когда включена голосовая функциональность;
  • добровольно отправленные фотографии, видео и документы;
  • пользовательские предпочтения;
  • в будущем — информацию об обучении в AIRA Academy;
  • техническую информацию, необходимую для безопасности и работы сервиса.

3. Цели обработки

Данные могут использоваться для ответа на запросы пользователя, поддержания контекста разговора, персонализации, работы AIRA Academy, исследования AI-инструментов по запросу пользователя, обеспечения безопасности, диагностики ошибок и работы сервиса.

4. Поставщики AI и API

Некоторый контент может передаваться внешним поставщикам AI/API, когда это необходимо для выполнения запроса пользователя. В текущем Telegram MVP содержимое сообщений может обрабатываться OpenAI API для генерации ответов AIRA. Условия обработки и хранения данных такими поставщиками определяются их собственными правилами.

5. Telegram

Telegram отдельно обрабатывает данные в соответствии с собственными правилами конфиденциальности. AIRA не контролирует независимую обработку данных Telegram.

6. Память и разделение данных

Не каждое сообщение становится постоянной памятью. В текущем MVP память разговора может быть временной и локальной для процесса: например, она может быть утрачена при перезапуске сервиса. Данные пользователей должны быть изолированы друг от друга.

7. Голосовые сообщения

Голосовые сообщения могут обрабатываться для распознавания речи. AIRA не использует голос пользователя автоматически для клонирования голоса или обучения. Настоящая политика не утверждает, что голосовые сообщения хранятся постоянно.

8. Удаление данных

Команда /delete_my_data удаляет контролируемое AIRA локальное состояние разговора там, где эта функция реализована в текущей версии. Команда не удаляет данные, которые независимо хранят или обрабатывают Telegram, OpenAI или другие внешние поставщики.

9. Безопасность

AIRA стремится защищать учетные данные, ограничивать доступ и минимизировать хранение ненужных данных. Однако ни один способ передачи или хранения данных не обеспечивает абсолютной безопасности, и AIRA не может ее гарантировать.

10. Несовершеннолетние

Текущий Telegram MVP пока не запущен как специализированный детский сервис. До публичного открытия AIRA Academy для несовершеннолетних должны быть внедрены дополнительные меры безопасности детей и защиты их конфиденциальности.

11. Cookies, аналитика и отслеживание

Эта страница не использует аналитику или трекеры, не подключает внешний JavaScript и не добавляет cookies от имени AIRA.
