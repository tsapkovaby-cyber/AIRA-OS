# Initial Agent Catalog

| Agent | Autonomy | Allowed purpose | Explicit boundary |
|---|---:|---|---|
| Research | 2 | Web research, knowledge read, research-memory write, candidates | No publishing, Founder-private data, credentials, brand or monetization |
| Knowledge | 2 | Validate research; read/write knowledge and graph links | No publication, external messaging, Founder-private data |
| Memory | 2 | Approved memory read/write, archive, version | No unapproved deletion, default external tools, publishing |
| Content | 2 | Verified-knowledge briefs and drafts | No default web, publication, approval, credentials |
| Guardian | 2 | Evidence/policy review, review records, workflow block | No publication, source edits, Constitution/permission changes or Founder override |
| Analytics | 2 | Read metrics/publication metadata; report and recommend | No personality changes, publication, history edits |
| Business | 1 | Approved market research and proposals | No transactions, publication, pricing, contracts or commitments |
| Publishing | 3 | Publish approved objects through approved adapters | No editing, approval, research, credentials, or unapproved publication; concurrency 1 |
| CEO Assistant | 1 | Dashboards, briefings, approvals explanation, planning requests | No Founder impersonation, publication, strategy changes, or financial execution |

Adding a type requires approved catalog documentation and registry changes. No new business roles are introduced here.
