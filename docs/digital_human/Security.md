# Security

Canonical references are sensitive IP. Production adapters must enforce least-privilege download and agent access, encryption, immutable/versioned backup, hash verification and audit logging. Provider profiles record retention, training use, privacy, commercial use, region and Founder approval. References may be disclosed only when the selected approved task needs them; unrelated Founder/private project data must never enter provider payloads.

New tools must complete research, risk review, experiment approval and controlled testing before receiving canonical assets. Publishing requires identity and brand checks, Guardian, Founder approval and applicable AI disclosure.
