# Voice Identity Architecture

Sprint 019 places canonical identity above adapters:

`Approved text → safety → pronunciation → identity lock → speech profile → router
→ provider → quality and identity evaluation → Guardian → Founder review → asset`.

The engine models consent, immutable references, profile state, language,
pronunciation, controlled emotion and pace, provider profiles, requests, assets,
feedback, budgets and lineage. Only one `ACTIVE` canonical profile is intended;
creating another requires an explicit Founder versioning workflow.

The speech provider receives approved text and a policy-approved external profile.
It cannot invent AIRA's response or receive an unrestricted master path.
