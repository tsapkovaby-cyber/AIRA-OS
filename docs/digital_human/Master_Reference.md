# Master Reference

`AIRA_MASTER_REFERENCE_V1` is registered as Founder-approved, read-only Asset Storage metadata with a protected file reference and SHA-256 hash. The repository intentionally does not invent or embed a replacement image. Attempts to overwrite, delete, edit, promote or demote the master are denied. A future replacement must use an explicit Founder workflow, a new immutable asset/version and audit history. Canonical storage requires encrypted durable storage, versioned backup, restore testing and a critical-incident alert for loss or hash mismatch.
