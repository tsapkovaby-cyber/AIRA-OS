# Visual Generation

Requests model purpose, platform, scene, wardrobe, pose, expression, camera, lighting, supported aspect ratio, references, task profile, provider policy, candidate count and cost ceiling. Prompts assemble versioned IDENTITY, SCENE, WARDROBE, POSE, EXPRESSION, CAMERA, LIGHTING, BRAND, QUALITY and NEGATIVE layers.

The router checks Founder approval, health, capabilities, allow-list and cost. Adapters own provider-specific settings and expose generation, editing, variation, capability, cost and health operations. Daily/monthly limits stop high-cost execution with `WAITING_FOUNDER_APPROVAL`. Cost per approved asset is derived from generation/edit/upscale spend and rejected count in the production metrics adapter.
